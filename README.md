# أرضي V1 - Web
نسخة ويب Responsive من واجهة تطبيق أرضي، تعمل على الهاتف والكمبيوتر.
هذه النسخة Frontend تجريبية. لربط تسجيل الدخول والاستثمار الحقيقي، اربطها بالـBackend وقاعدة البيانات الموجودة في مشروع V1، مع استكمال التكاملات القانونية والتنظيمية المطلوبة قبل التشغيل المالي الفعلي.

## تشغيل
يمكن فتح `index.html` مباشرة في المتصفح.
وللنشر: ارفع الملفات إلى أي استضافة Static Website.
